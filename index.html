CS Hub

SaaS Product Specification

Comprehensive academic support platform for Computer Science students

Version 1.0 July 2026

Prepared for: Development Team

Confidential – Internal Use Only

1. Executive Overview

CS Hub is a comprehensive SaaS academic management platform designed specifically for Computer Science departments. It bridges the gap between traditional Learning Management Systems (LMS) and the specialized needs of CS students through integrated AI tools, collaborative features, and department-specific workflows.

Target Users: Computer Science Students, Lecturers, Department Administrators (HOD, Coordinators)

Deployment: Cloud-based SaaS with offline capabilities, accessible via web and mobile applications.

2. Detailed Feature Specifications

MODULE 1: DASHBOARD (HOME)

1.1 Personalized Welcome Widget

  • User-specific greeting based on time of day (Good Morning/Afternoon/Evening)
  • Student ID Display with profile picture placeholder
  • Quick Stats Cards:
    • Current CGPA (with trend indicator)
    • Upcoming Deadlines (count + nearest deadline)
    • Unread Messages (from lecturers/admin)
    • Pending Assignments
    • Unwatched Recordings

1.2 Calendar Widget

  • Monthly/Weekly View toggle
  • Events Color-Coded:
    • 🟢 Academic (Classes, Lectures)
    • 🔴 Exams/Tests
    • 🟡 Assignment Deadlines
    • 🔵 Department Events
    • 🟣 Meetings (Supervision, Project)
  • Click to Expand for event details

1.3 Quick Link Cards

  • Dynamic Shortcuts based on user role:
    • Student: Courses → Assignments → CBT → AI Assistant
    • Lecturer: Course Management → Create Quiz → Grade Submissions
    • Admin: Announcements → User Management → Reports

1.4 Announcement Feed

  • Hierarchical Display:
    1. Department-wide (HOD/Dean)
    2. Course-specific (Lecturers)
    3. Personal (Tutor/Advisor)
  • Read/Unread Status
  • Priority Markers (Urgent, Important, Informational)

1.5 Motivational Quote & Weather (Optional)

  • Rotating tech-related motivational quotes
  • Weather widget with location detection (optional config)

MODULE 2: ACADEMIC & COURSE MANAGEMENT

2.1 Course Registration / Course Catalog

Features:

  • Browse Courses by session/semester
  • Filter/Search: Department, Course Code, Lecturer, Level, Electives
  • Course Details: Lecturer info, credits, prerequisites, syllabus summary
  • Registration Workflow:
    • Add/Remove courses (within deadline)
    • HOD approval workflow
    • Waitlist functionality for capped courses
  • Registration History for past sessions

Data Schema:

Course { courseId: string courseCode: string courseTitle: string creditUnit: number semester: 'First' | 'Second' level: 100 | 200 | 300 | 400 | 500 lecturers: [User] prerequisites: [Course] maxCapacity: number enrolledStudents: [User] registrationDeadline: datetime }

2.2 Timetable Module

Features:

  • Personalized Weekly View with:
    • Course codes
    • Venue/Room number
    • Lecturer name
    • Duration (Start/End time)
  • Conflict Detection (overlapping courses)
  • Export Functionality: Google Calendar (.ics), Outlook, PDF printable
  • Color Coding per course

Data Schema:

TimeSlot { day: 'Mon' | 'Tue' | 'Wed' | 'Thu' | 'Fri' startTime: time endTime: time course: Course venue: string lecturer: User type: 'Lecture' | 'Lab' | 'Tutorial' | 'Exam' }

2.3 Course Content Management

For Lecturers:

  • Upload Content: Drag & drop interface
  • Content Types: Lecture Slides (PDF, PPTX, Keynote), Lecture Notes (DOCX, MD, HTML), Video Recordings (MP4, WebM), Supplementary Materials (PDFs, ZIP files)
  • Folder Organization: Weekly topics or units
  • Bulk Upload Support
  • Version Tracking (previous versions retained)
  • Access Control: Published/Draft, visible to students

For Students:

  • Download Options: Single file or bulk
  • Mark as Read/Viewed tracking
  • Offline Sync for downloaded materials
  • Rate/Provide Feedback on content quality

Storage Specifications: File size limit 200MB per file, 10GB per course, auto-optimize images, video transcoding for mobile.

2.4 Assignment Submission Portal

For Students:

  • View Assignments: List with deadlines, instructions, marking rubric
  • Submit Work: Multiple file uploads, text entry, link submissions (Google Drive, GitHub)
  • Submission Status: Submitted, Late, Resubmitted, Graded
  • View Feedback & Grades
  • Submission History

For Lecturers:

  • Create Assignments: Title, Description, Instructions, Deadline with timezone, Max file size and type restrictions, Marking rubric (criteria with weights)
  • Assignment Management: Extend deadlines (individual or batch), Bulk download submissions, Inline commenting, Award grades and feedback
  • Plagiarism Checker (Integration): Turnitin API, Code plagiarism detection (MOSS integration), Similarity report generation

Assignment Data Model:

Assignment { id: string course: Course title: string description: text instructions: text deadline: datetime maxScore: number rubric: [RubricCriterion] submissions: [Submission] isLateSubmissionAllowed: boolean latePenalty: percentage }

2.5 Grade Book / Result Checker

  • Grade Dashboard: Overall performance summary, Course-by-course breakdown, Semester GPA, CGPA with trend graph
  • Detailed View: Assignment grades, Test/Exam scores, Final grade calculation
  • Grade Annotations: Lecturer comments
  • Export: PDF report, Excel download
  • Auto-Calculation: Weighted grading with formula editor

Data Schema:

Grade { student: User course: Course session: Session components: [ { type: 'Assignment', score, weight, max } { type: 'Midterm', score, weight, max } { type: 'Exam', score, weight, max } ] finalGrade: number letterGrade: string semesterGPA: number cgpa: number }

2.6 Exam Schedule & Past Questions Bank

Exam Schedule: Calendar View, Personalized Filter, Exam Details (Date, Time, Venue, Duration), Proctoring Information, Pre-Exam Checklist.

Past Questions Bank: Browse by Course, Year, Semester; Searchable by keywords, topics; Multiple formats: PDF, Images, Interactive CBT; Filter by Exam Type; Flagging for "Likely Questions"; Download/Print; Lecturer-Approved tag.

Data Schema:

PastQuestion { id: string course: Course session: string semester: string examType: 'Midterm' | 'Final' | 'Quiz' | 'CAT' filePath: string isLecturerApproved: boolean uploadedBy: User tags: [string] downloads: number }

2.7 CGPA Calculator & Progress Tracker

  • CGPA Calculator: Input grades per course, Auto-calculate GPA, Semester-level aggregation, Year-level summary, What-If Analysis (simulate grade scenarios), Target Calculator (determine required grades)
  • Progress Tracker: Completion Progress (% of courses completed), Credit Progress (Earned vs Required credits, Recommended next courses), Performance Trends (line graph, radar chart), Academic Alerts (probation warnings, excellent performance recognition), Milestones (level progression, special recognitions).

Algorithm: CGPA = (Σ(GradePoint × CreditUnits)) / Σ(CreditUnits)

9. Key Features Deep-Dive

9.1 AI Student Assistant

  • 24/7 Availability for student queries
  • Context-Aware Responses: Course-specific (trained on course materials), Departmental (policy, procedures), General academic guidance
  • Capabilities: Clarify assignment instructions, Explain concepts from lecture notes, Recommend study resources, Provide practice questions, Schedule reminders
  • Integration: Search through uploaded lecture notes, Access past questions for practice, Reference course syllabus

9.2 Voice-to-Text Lecture Transcription

  • Real-time Transcription during live lectures
  • Speaker Diarization (identifies different speakers)
  • Automatic Summarization
  • Searchable Transcripts
  • Export to Notes (Markdown/PDF)
  • Multi-language Support
  • Integration with Lecture Recordings

9.3 Offline Access

  • Downloaded Materials: Lecture notes (PDF, DOCX), Video recordings (with subtitles), Past questions, Quizzes (take offline, sync later)
  • Sync Engine: Auto-sync when online, Conflict resolution for submissions, Progress tracking across devices
  • Storage Management: Selective download, Auto-cleanup for older materials, Quality selection (low/med/high for videos)
